# SamiAhmed7777/homebrew-tap

Homebrew tap for Cryptographic Triangles (tri7).

```
brew tap SamiAhmed7777/tap
brew install --cask cryptographic-triangles

The cask currently points at the **Windows** NSIS setup exe — an explicit
maintainer directive until a macOS build of tri7 ships.
```

Updated automatically by the tri7 repo's `distribute.yml` workflow on every
`v*` tag. Requires the tri7 repo to be public (release-asset URLs).
